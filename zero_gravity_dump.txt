# AGENT DETAILS

# Agent 1 — Profile Extraction

Input:

* resume PDF
* LinkedIn About text (optional)
* GitHub URL
* preferences

Process:

* PyMuPDF extracts text
* Gemini converts into structured profile JSON

Output Schema:

```json
{
  "name": "",
  "skills": [],
  "experience_years": 0,
  "roles": [],
  "location": "",
  "salary_expectation": {},
  "remote_preference": ""
}
```

---

# Agent 2 — Job Discovery

Uses:

* JSearch API

Responsibilities:

* fetch jobs
* normalize responses
* fallback to mock jobs if API fails

Output Schema:

```json
{
  "id": "",
  "title": "",
  "company": "",
  "location": "",
  "remote": true,
  "salary_min": 0,
  "salary_max": 0,
  "description": "",
  "posted_at": "",
  "url": ""
}
```

---

# Agent 3 — Match Scoring

Input:

* profile JSON
* jobs JSON

Output:

```json
{
  "match_score": 0,
  "skill_overlap": 0,
  "experience_overlap": 0,
  "location_match": 0,
  "remote_compatibility": 0,
  "ats_keyword_similarity": 0,
  "salary_match": 0,
  "job_freshness": 0,
  "estimated_shortlist_probability": 0,
  "reasoning": []
}
```

Scoring Logic:

* 40% skill overlap
* 20% ATS similarity
* 15% location
* 10% salary
* 10% experience
* 5% AI reasoning boost

---

# Agent 4 — Resume Tailoring

Responsibilities:

* rewrite summary
* reorder skills/projects
* inject ATS keywords
* preserve layout structure

Output:

* tailored PDF resume

Generation:

* Gemini → plain text sections
* ReportLab → PDF generation

Hero Feature:
Live side-by-side resume comparison.

---

# Agent 5 — Outreach Drafting

Responsibilities:

* generate outreach email
* personalized subject/body
* editable by user
* send with resume attachment

Output:

```json
{
  "subject": "",
  "email_body": "",
  "short_cover": ""
}
```

Email sending:

* Nodemailer
* Gmail App Password

---

# Agent 6 — Tracking & Scheduling

Responsibilities:

* application tracking
* interview scheduling
* overlap detection
* status management

Statuses:

* Applied
* Pending
* Interview
* Rejected

Interview scheduling is partially simulated for demo reliability.
